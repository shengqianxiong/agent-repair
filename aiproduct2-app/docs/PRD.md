# aiProduct2 旧衣服回收小程序（C 端）PRD

## 1. 产品目标
- 面向 C 端用户提供旧衣免费上门回收服务。
- 提供两种回收用途：环保金奖励、公益捐赠证书。
- 覆盖预约、订单追踪、奖励提现、礼品兑换、证书查看全流程。

## 3. 业务流程
1. 用户在首页查看规则与奖励政策，进入预约页。
2. 填写地址、日期时段、衣物信息、用途后提交预约。
3. 订单进入「待上门」状态，支持取消并同步第三方。
4. 取件后回传称重数据，发放环保金或生成公益证书。
5. 用户在奖励中心查看余额、明细、提现、礼品兑换。

## 4. 页面关键交互

### 4.1 首页
- Banner 展示「旧衣新生 绿色未来」。
- 快捷入口：预约免费上门、捐赠获取证书。
- 卡片展示：回收规则、奖励政策、公益项目进度。

### 4.2 预约页
- 地址卡片、未来 7 天日期选择、2 小时时段选择。
- 旧衣类型多选，预估重量步进器。
- 回收用途单选：环保金 / 公益证书。
- 备注输入，提交后跳转订单页。

### 4.3 订单页
- 状态 Tab：全部、待上门、已取件、已完成、已取消。
- 订单卡展示：编号、上门时间、地址、类型、奖励与重量。
- 待上门订单支持取消。

### 4.4 奖励中心
- 顶部钱包卡：余额、累计奖励、累计回收重量。
- 明细流水展示收入/支出。
- 底部弹层提现（微信零钱）。

### 4.5 兑换礼品
- 显示可用积分与奖励余额。
- 分类筛选与礼品网格列表。
- 礼品卡片支持立即兑换。

### 4.6 公益证书
- 证书主视图、证书编号、用户姓名、捐赠重量、日期、盖章。

### 4.7 个人中心
- 地址管理、我的订单、我的奖励、我的证书、在线客服、常见问题入口。

## 6. 技术与约束
- 技术栈：uni-app + Vue 3 + uview-plus。
- H5 端口：`8080`（`vite.config.js` 与 `manifest.json` 已配置）。
- 全站接口统一由 `src/utils/request.js` 发起，Header 使用 `token`。
- 登录/注册类接口调用时禁用 token 注入（`requireToken: false`）。
