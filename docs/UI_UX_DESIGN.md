# E2E测试产品 1781018045897 UI/UX 设计要求文档

## 1. 文档目标

本文档用于指导“E2E测试产品 1781018045897”的界面设计与 AI UI 草图生成。产品基于极简登录与账号管理流程，包含管理端和用户端两类界面：

- 管理端：管理员登录、后台基础框架、账号列表、账号新增、账号编辑。
- 用户端：用户登录、登录成功后的个人中心/入口页。

设计目标是保证登录、鉴权、账号管理等核心流程清晰、稳定、易测试，界面简洁且状态反馈明确。

## 2. 产品定位与体验关键词

### 2.1 产品定位

面向 E2E 自动化测试场景的轻量级登录与账号管理产品。界面应降低视觉复杂度，让测试用例能够稳定定位关键组件，并让用户快速完成登录、查询、新增、编辑、删除等任务。

### 2.2 体验关键词

- 简洁：核心任务优先，减少无关装饰。
- 清晰：页面标题、按钮文案、表单提示明确。
- 稳定：布局区域固定，核心元素位置可预测。
- 专业：管理端采用企业后台风格；用户端采用轻量移动端卡片风格。
- 可测试：按钮、表单、表格、弹窗等组件状态明显，便于自动化识别。

## 3. 设计风格

### 3.1 整体风格

- 管理端采用现代企业后台风格：左侧深色导航栏、顶部白色工具栏、内容区浅灰背景、白色卡片承载业务内容。
- 用户端采用移动优先风格：顶部品牌区使用渐变背景，表单与信息模块使用圆角白色或深色卡片。
- 视觉层级以“标题 -> 表单/筛选 -> 数据表格 -> 操作反馈”为主线。
- 图形装饰保持克制，可使用轻量渐变、阴影、圆角和状态色，不使用复杂插画。

### 3.2 品牌感

- 产品名称：`E2E测试产品 1781018045897`。
- 管理端显示名称建议：`E2E测试产品 · 管理端`。
- 用户端显示名称建议：`E2E测试产品`。
- 可在登录页标题下展示副标题：`极简登录与账号管理系统`。

### 3.3 页面氛围

- 管理端：理性、稳定、高对比、低干扰。
- 用户端：轻量、友好、快速进入。
- 所有页面避免大面积复杂图片背景，以提升加载稳定性与测试稳定性。

## 6. 各页面布局说明

### 6.1 管理端管理员登录页

#### 页面目标

管理员输入账号和密码完成登录，登录成功后进入账号列表。

#### AI 草图布局描述

- 画布：桌面端，推荐尺寸 `1440 x 900`。
- 背景：全屏紫蓝渐变背景。
- 主体：页面正中央放置白色登录卡片。
- 卡片尺寸：宽度约 `400px`，高度根据内容自适应，内边距 `32px`。
- 卡片样式：圆角 `12px`，轻阴影。
- 卡片内容从上到下排列：
  1. 标题：`管理员登录`，居中，字号 `22px`，深色文字。
  2. 副标题：`E2E测试产品 1781018045897`，居中，次级文字，可选。
  3. 账号输入框：左侧标签 `账号`，占位符 `请输入账号`。
  4. 密码输入框：左侧标签 `密码`，占位符 `请输入密码`，右侧显示密码切换图标。
  5. 主按钮：`登录`，通栏宽度，主品牌色。

#### 交互状态

- 输入框聚焦：边框变为主品牌色。
- 未输入账号或密码点击登录：对应输入框下方显示错误提示。
- 登录中：登录按钮显示加载状态并禁用重复点击。
- 登录成功：顶部或页面内出现成功提示 `登录成功`，跳转账号列表。
- 登录失败：显示错误提示，不清空已输入账号。

### 6.2 管理端后台框架

#### 页面目标

为管理端所有业务页面提供一致的导航、标题、账号状态和退出入口。

#### AI 草图布局描述

- 画布：桌面端，推荐尺寸 `1440 x 900`。
- 整体结构：左侧固定导航 + 右侧主区域。
- 左侧导航：
  - 宽度 `220px`，高度占满屏幕。
  - 背景色 `#1D1E2C`。
  - 顶部 Logo 区高度 `56px`，文字 `E2E测试产品 · 管理端`。
  - 菜单项垂直排列，默认包含 `账号管理`。
  - 当前菜单高亮使用 `#409EFF`。
- 右侧区域：
  - 顶部栏高度约 `56px`，白色背景，下边框。
  - 顶部栏左侧显示当前页面标题，如 `账号管理`。
  - 顶部栏右侧显示 `当前账号：admin` 和 `退出登录` 按钮。
  - 主内容区背景 `#F5F7FA`，内边距 `16px`。

#### 交互状态

- 点击菜单项：右侧内容区切换页面，菜单高亮同步。
- 点击退出登录：清除登录态并跳转到管理员登录页。
- Token 失效：自动返回登录页，并显示登录过期提示。

### 6.3 管理端账号列表页

#### 页面目标

管理员查看账号列表，支持按账号关键词查询、新增账号、编辑账号、删除账号。

#### AI 草图布局描述

- 页面位于后台框架内容区。
- 使用一张白色内容卡片承载全部内容，圆角 `8px`，内边距 `16px`。
- 卡片顶部为搜索区：
  - 横向表单布局。
  - 标签 `账号` + 输入框，占位符 `请输入账号关键词`，宽度约 `220px`。
  - 右侧按钮：`搜索` 主按钮、`重置` 次按钮。
- 搜索区下方为表格工具栏：
  - 左侧标题 `账号列表`，加粗。
  - 右侧按钮 `新增账号`，主按钮。
- 数据表格：
  - 表头：`账号`、`创建时间`、`账号状态`、`操作`。
  - 表格有边框、斑马纹。
  - `账号状态` 使用标签显示：
    - `正常`：绿色标签。
    - `禁用`：红色标签。
  - 操作列固定在右侧，包含文本按钮：
    - `编辑`：蓝色链接样式。
    - `删除`：红色链接样式。
- 表格底部右侧为分页：
  - 显示总数。
  - 支持每页 `10 / 20 / 50`。
  - 显示上一页、页码、下一页。

#### 空状态

- 当无数据时，表格中部显示空状态插画或简单图标。
- 文案：`暂无账号数据`。
- 若为搜索无结果，可显示：`未找到匹配账号，请调整关键词`。

#### 加载状态

- 表格加载时显示局部 loading 蒙层。
- 搜索按钮在请求中可短暂禁用，避免重复触发。

#### 删除确认

- 点击 `删除` 后弹出确认框：
  - 标题：`删除确认`。
  - 内容：`确认永久删除账号「账号名」吗？`。
  - 左侧/次按钮：`取消`。
  - 右侧/危险按钮：`确认删除`。
- 当前登录管理员账号的删除按钮禁用，并在 hover 或点击时提示：`不可删除当前登录的管理员账号`。

### 6.4 管理端新增账号弹窗

#### 页面目标

在账号列表页内快速新增账号。

#### AI 草图布局描述

- 弹窗宽度约 `420px`，居中显示。
- 背景遮罩为半透明黑色。
- 弹窗标题：`新增账号`。
- 表单字段：
  1. `账号` 输入框，占位符 `请输入账号`。
  2. `初始密码` 密码输入框，占位符 `请输入初始密码`，支持显示/隐藏密码。
- 底部操作区右对齐：
  - `取消` 次按钮。
  - `确定` 主按钮。

#### 交互状态

- 点击遮罩或取消：关闭弹窗，清空未提交内容。
- 点击确定：
  - 校验必填项。
  - 提交中确定按钮显示 loading。
  - 成功后显示 `新增成功`，关闭弹窗并刷新列表。
  - 失败时保留输入内容并显示错误提示。

### 6.5 管理端编辑账号页

#### 页面目标

管理员修改账号状态或重置密码。

#### AI 草图布局描述

- 页面位于后台框架内容区。
- 使用白色内容卡片，圆角 `8px`，内边距 `16px`。
- 表单最大宽度约 `480px`，左对齐。
- 表单字段从上到下：
  1. `账号`：禁用输入框，仅展示账号名。
  2. `重置密码`：密码输入框，占位符 `留空则不修改密码`。
  3. `账号状态`：单选按钮组，选项 `正常`、`禁用`。
  4. 操作按钮：`保存` 主按钮、`返回` 次按钮。

#### 交互状态

- 进入页面时加载账号详情，加载期间显示骨架屏或表单 loading。
- 账号字段不可编辑，视觉上使用浅灰禁用态。
- 密码留空时不修改密码。
- 点击保存：
  - 状态必选。
  - 保存按钮显示 loading。
  - 成功后提示 `保存成功` 并返回账号列表。
- 点击返回：不保存修改，直接返回账号列表。

### 6.6 用户端登录页

#### 页面目标

普通用户输入账号和密码完成登录，登录成功后进入首页或个人中心。

#### AI 草图布局描述

- 画布：移动端，推荐尺寸 `375 x 812`。
- 背景：顶部紫蓝渐变，下半部分浅灰背景。
- 页面内边距：左右 `24px` 等效。
- 顶部品牌区：
  - 距顶部约 `60px`。
  - 主标题：`用户登录`，白色，大字号。
  - 副标题：`E2E测试产品 1781018045897` 或 `极简登录系统`，白色半透明。
- 表单卡片：
  - 位于品牌区下方。
  - 白色背景，圆角 `24rpx` 或 `12px`。
  - 内边距 `24px`。
  - 字段纵向排列：
    1. `账号` 输入框，占位符 `请输入账号`，带清除按钮。
    2. `密码` 输入框，占位符 `请输入密码`，密码模式，带清除按钮。
  - 主按钮 `登录`，在表单下方，通栏宽度。

#### 交互状态

- 账号为空点击登录：toast 显示 `请输入账号`。
- 密码为空点击登录：toast 显示 `请输入密码`。
- 登录中：按钮 loading，不允许重复点击。
- 登录成功：toast 显示 `登录成功`，短暂停留后进入首页或个人中心。
- 登录失败：toast 显示接口返回错误信息。

### 6.7 用户端个人中心/登录成功页

#### 页面目标

用于展示用户已登录状态，并提供常用功能入口。若 AI 草图只生成最小闭环，至少需要展示账号信息和退出/返回入口。

#### AI 草图布局描述

- 画布：移动端，推荐尺寸 `375 x 812`。
- 背景：深色或浅灰均可，推荐延续深色会员中心风格。
- 顶部导航：
  - 标题 `我的`。
  - 深色背景 `#1A1A2E`，标题白色。
- 用户信息头部：
  - 使用深紫到深蓝渐变背景。
  - 左侧圆形头像，占位图标即可。
  - 中部显示昵称或账号，未获取昵称时显示当前账号。
  - 下方显示标签 `普通会员` 或 `已登录`。
  - 右侧箭头图标表示可进入详情。
- 数据统计卡片：
  - 三列布局。
  - 示例字段：`积分`、`订单`、`预约`。
  - 数字突出显示，标签为次级文字。
- 常用功能列表：
  - 使用分组卡片或 cell list。
  - 条目：`我的订单`、`我的预约`、`会员中心`、`我的积分`、`消息通知`。
  - 每行左侧图标，中间标题，右侧箭头。
- 底部导航：
  - 若草图包含完整 App 框架，可显示底部 TabBar。
  - 当前项高亮为 `我的`。

#### 交互状态

- 下拉刷新：更新用户信息与统计数据。
- 点击功能项：进入对应页面，若页面未实现可显示占位状态。
- 未登录或 token 失效：返回用户登录页。

## 7. 组件规范

### 7.1 按钮

#### 类型

| 类型 | 样式 | 使用场景 |
|---|---|---|
| 主按钮 | 主品牌色背景，白色文字 | 登录、搜索、保存、新增、确定 |
| 次按钮 | 白底灰边框，深色文字 | 重置、返回、取消 |
| 危险按钮 | 红色文字或红色背景 | 删除、确认删除 |
| 链接按钮 | 无背景，蓝色或红色文字 | 表格内编辑/删除 |

#### 状态

- 默认：颜色清晰，文字可读。
- Hover/Active：颜色略加深。
- Loading：显示旋转 loading，禁用重复点击。
- Disabled：透明度降低，鼠标不可点击，移动端不可触发。

### 7.2 输入框

- 高度：管理端 `32px-40px`；移动端 `44px-48px` 等效。
- 圆角：`4px-8px`。
- 必填字段需在校验失败时展示错误文案。
- 密码输入框需要提供显示/隐藏密码能力。
- 支持清除输入内容，尤其是登录账号与搜索关键词。
- Placeholder 使用次级文字色，不应过深。

### 7.3 表单

- 管理端表单标签右对齐，标签宽度建议 `80px-100px`。
- 移动端表单标签左对齐或置于输入框上方。
- 表单项垂直间距：管理端 `18px-24px`，移动端 `24rpx-32rpx`。
- 错误提示紧贴字段下方，使用错误色。

### 7.4 表格

- 表头背景可使用浅灰或白色，文字加粗。
- 表格行高度建议 `48px`。
- 支持 loading、空状态、分页。
- 操作列固定在右侧，避免横向滚动时丢失操作入口。
- 状态字段必须使用颜色标签，而不仅是纯文字。

### 7.5 标签

- `正常`：绿色成功标签。
- `禁用`：红色危险标签。
- `已登录`、`普通会员`：可使用橙色或紫色轻量标签。
- 标签圆角建议 `4px-12px`，文字保持单行。

### 7.6 弹窗

- 管理端弹窗宽度优先 `420px`。
- 标题左对齐，底部按钮右对齐。
- 遮罩层透明度约 `45%`。
- 危险确认弹窗必须突出风险文案和危险按钮。

### 7.7 Toast / Message

- 成功：绿色图标 + 成功文案。
- 警告：黄色图标 + 操作限制文案。
- 错误：红色图标 + 接口或校验错误。
- 显示时长建议 `1.5s-3s`。
- 移动端 toast 居中或底部浮层均可，但不遮挡关键按钮太久。

### 7.8 卡片

- 管理端内容卡片：
  - 背景 `#FFFFFF`。
  - 圆角 `8px`。
  - 内边距 `16px`。
- 登录卡片：
  - 圆角 `12px` 或更大。
  - 阴影适中，用于从背景中浮起。
- 移动端卡片：
  - 圆角 `12px-16px`。
  - 左右外边距 `16px-24px`。

## 8. 交互说明

### 8.1 登录流程

```text
进入登录页
→ 输入账号和密码
→ 点击登录
→ 前端校验必填
→ 按钮进入 loading
→ 调用登录接口
→ 成功：保存 token 和账号信息，展示成功提示，跳转目标页
→ 失败：展示错误提示，停留当前页
```

### 8.2 账号查询流程

```text
进入账号列表
→ 自动加载第一页
→ 输入账号关键词
→ 点击搜索
→ 页码重置为 1
→ 表格显示 loading
→ 返回结果后刷新表格和分页
```

### 8.3 新增账号流程

```text
点击新增账号
→ 打开新增弹窗
→ 输入账号和初始密码
→ 点击确定
→ 校验必填
→ 提交中按钮 loading
→ 成功：关闭弹窗，提示新增成功，刷新列表
→ 失败：弹窗保持打开，显示错误提示
```

### 8.4 编辑账号流程

```text
点击编辑
→ 进入编辑账号页
→ 加载账号详情
→ 修改密码或状态
→ 点击保存
→ 提交中按钮 loading
→ 成功：提示保存成功，返回列表
→ 失败：停留页面并展示错误提示
```

### 8.5 删除账号流程

```text
点击删除
→ 判断是否为当前登录账号
→ 当前账号：阻止删除并提示
→ 非当前账号：弹出删除确认
→ 点击确认删除
→ 成功：提示删除成功，刷新列表
→ 点击取消：关闭确认框，无数据变化
```

### 8.6 鉴权与异常

- 未登录访问管理端页面：跳转管理员登录页。
- 未登录访问用户端已登录页面：跳转用户登录页。
- Token 过期或接口返回未授权：清除本地登录态并跳转登录页。
- 接口异常：显示错误信息，页面保留当前可用数据。
- 网络慢：按钮和表格必须有 loading 状态，避免用户重复操作。

## 9. 响应式要求

### 9.1 管理端桌面端

- 主要适配宽度：`1280px`、`1366px`、`1440px`、`1920px`。
- 左侧导航固定 `220px`。
- 顶部栏固定高度约 `56px`。
- 内容区随屏幕宽度自适应。
- 表格列宽不足时允许横向滚动，操作列保持固定。

### 9.2 管理端平板与窄屏

- 当屏幕宽度小于 `1024px`：
  - 左侧导航可收起为图标栏，宽度约 `64px`。
  - 顶部栏账号信息可缩短为头像或账号名。
  - 搜索表单可从横向排列改为换行排列。
- 当屏幕宽度小于 `768px`：
  - 管理端可采用顶部导航 + 抽屉菜单。
  - 表格保留横向滚动。
  - 弹窗宽度调整为屏幕宽度的 `90%`。

### 9.3 用户端移动端

- 主要适配宽度：`320px`、`360px`、`375px`、`390px`、`414px`。
- 使用安全区适配顶部状态栏和底部 Home Indicator。
- 表单卡片左右边距不小于 `16px`。
- 登录按钮始终保持通栏显示。
- 功能列表单行文字过长时省略，避免撑破布局。

### 9.4 高度适配

- 登录页内容在低高度屏幕下允许整体上移或滚动。
- 管理端内容区高度超出时只滚动内容区域，导航与顶部栏保持稳定。
- 移动端个人中心内容超过一屏时使用纵向滚动，底部 TabBar 固定。

## 10. 可访问性与可测试性要求

- 所有输入框必须有明确标签和占位符。
- 主要按钮文案必须唯一且语义明确，如 `登录`、`搜索`、`新增账号`、`保存`。
- 错误提示不能只依赖颜色，应有文字说明。
- 状态标签需要同时使用颜色和文字。
- 删除等危险操作必须二次确认。
- 禁用按钮需要视觉区分，并且不响应点击。
- UI 草图中应保留明显的表单字段边界、按钮边界和表格列分隔。
- 建议为关键元素预留稳定标识：
  - 登录按钮：`login-submit`
  - 账号输入框：`account-input`
  - 密码输入框：`password-input`
  - 新增账号按钮：`account-create`
  - 保存按钮：`account-save`
  - 删除确认按钮：`account-delete-confirm`
