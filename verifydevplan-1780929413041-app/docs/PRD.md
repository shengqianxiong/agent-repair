# PRD：VerifyDevPlan-1780929413041

## 1. 项目概述

VerifyDevPlan-1780929413041 是一个轻量级商品浏览用户端应用，基于 uni-app + Vue 3 + uview-plus 构建，支持 H5 与微信小程序多端运行。

## 2. 功能范围

### 2.1 用户登录

- 路由：`/pages/login/login`
- 启动首屏，未登录用户默认进入登录页
- 表单字段：用户名、密码
- 登录成功后保存 token 与 userInfo，跳转商品列表
- 已登录用户访问登录页自动跳转商品列表

### 2.2 商品列表

- 路由：`/pages/index/index`
- 登录成功后进入
- 支持关键词搜索、下拉刷新、上拉加载更多
- 点击商品卡片可查看详情（底部弹窗）
- 支持退出登录

## 3. 鉴权规则

- 全站 API 使用 Header `token` 鉴权（登录接口除外）
- 未登录访问受保护页面自动重定向至登录页
- token 失效（401）自动清除登录态并跳转登录页

## 4. 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 用户登录 | `/pages/login/login` | 启动首屏 |
| 商品列表 | `/pages/index/index` | 登录后首页 |

## 5. 技术栈

- uni-app 3.x + Vue 3
- uview-plus 3.x
- H5 开发端口：8080
- 本地 Mock 模式默认开启，可切换真实 API
