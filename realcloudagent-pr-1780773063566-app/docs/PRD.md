# RealCloudAgent-PR-1780773063566 产品需求文档

## 项目名称

RealCloudAgent-PR-1780773063566

## 需求概述

极简登录：三端（服务端、管理端、用户端）均提供登录页与登录 API，仅实现登录能力，不包含其他业务功能。

## 三端架构

| 端 | 目录 | 端口 | 对接路径 |
|---|---|---|---|
| 服务端 | `realcloudagent-pr-1780773063566-server` | 9294 | Context `/sqx_fast` |
| 管理端 | `realcloudagent-pr-1780773063566-admin` | 5173 | `/admin/**` |
| 用户端 | `realcloudagent-pr-1780773063566-app` | 8080 | `/app/**` |

## 功能范围

### 服务端

1. 提供管理端登录 API：`POST /admin/login`
2. 提供用户端登录 API：`POST /app/user/login`
3. 用户表与管理表持久化到 MySQL
4. 登录成功后返回 token，供各端后续请求鉴权使用

### 管理端

1. 登录页面：用户名 + 密码
2. 调用 `POST /admin/login` 完成登录
3. 登录成功保存 token 到本地存储

### 用户端

1. 登录页面：用户名 + 密码
2. 调用 `POST /app/user/login` 完成登录
3. 登录成功保存 token 与用户信息到本地存储
4. 登录成功后跳转首页，展示登录返回的用户信息，支持退出登录
