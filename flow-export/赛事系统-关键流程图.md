# 轻量级球馆赛事系统 — 关键交互流程图

> 本文件包含 Mermaid 源码，可在任何支持 Mermaid 的编辑器（VS Code、Typora、Obsidian、GitLab/GitHub）中直接渲染。
> 对应导出的图片见同目录 `out/` 下的 PNG / SVG 文件。

---

## 1. 整体主流程

```mermaid
flowchart TD
    A[新建赛事并配置赛制] --> B[导入/录入参赛选手]
    B --> C{赛制?}
    C -->|小组循环赛| D[自动分组]
    C -->|单败淘汰赛| E[自动生成对阵表]
    D --> F[人工微调并锁定分组]
    F --> G[生成小组对战赛程]
    E --> H[生成淘汰赛第一轮]
    G --> I[每场录入比分]
    H --> I
    I --> J{比赛全部结束?}
    J -->|否| I
    J -->|小组赛结束| K[自动排名+晋级判定]
    J -->|淘汰赛本轮结束| L[生成下一轮]
    L --> I
    K --> M[结束赛事]
    M --> N[赛事积分结算]
    N --> O[前端展示榜单/晋级名单]
```

## 2. 自动分组（小组循环赛）

```mermaid
flowchart TD
    A[点击一键分组] --> B{参赛人数校验}
    B -->|人数为0| B1[提示无可分组选手] --> Z[结束]
    B -->|正常| C[读取每组人数配置]
    C --> D{分组方式?}
    D -->|随机均分| E1[选手列表随机打乱]
    E1 --> E2[依序轮流分配进各组]
    D -->|按积分蛇形| F1[按历史积分降序排序]
    F1 --> F2[蛇形分配:1组2组..末组再末组..2组1组]
    E2 --> G[生成分组结果]
    F2 --> G
    G --> H{是否有余数选手}
    H -->|有| H1[余数选手补入人数最少的组]
    H -->|无| I[展示分组结果]
    H1 --> I
    I --> J{人工是否调换?}
    J -->|是| J1[拖拽调换选手所在组] --> I
    J -->|否| K[点击锁定分组]
    K --> L[分组状态置为已锁定, 可生成赛程]
```

---

## 3. 小组循环赛对战生成（两两对战）

```mermaid
flowchart TD
    A[分组已锁定] --> B[遍历每个小组]
    B --> C[取组内全部选手]
    C --> D[组内每两人生成一场对战]
    D --> E[写入 matches 表 状态=未开始]
    E --> F{还有下一组?}
    F -->|是| B
    F -->|否| G[赛程生成完成]
```

---

## 4. 单败淘汰赛对阵生成（含轮空）

```mermaid
flowchart TD
    A[读取参赛人数 N] --> B[计算 >=N 的最小2的幂次 M]
    B --> C[计算轮空数 = M - N]
    C --> D{分组方式?}
    D -->|随机| E1[选手随机排入签位]
    D -->|按积分| E2[按积分蛇形排种子位]
    E1 --> F[分配轮空签位给部分选手]
    E2 --> F
    F --> G[生成第一轮对阵]
    G --> H{该对位有轮空?}
    H -->|是| H1[轮空选手标记 轮空晋级 直接进下一轮]
    H -->|否| H2[生成正常对战 状态=未开始]
    H1 --> I[第一轮赛程生成完成]
    H2 --> I
```

## 5. 录入比分（核心高频操作）

```mermaid
flowchart TD
    A[管理员点击录入比分] --> B[弹窗输入选手1/选手2比分]
    B --> C{赛制类型?}
    C -->|淘汰赛| C1{比分是否分出胜负?}
    C1 -->|平局| C2[报错:淘汰赛必须分胜负] --> B
    C1 -->|有胜者| D[确定胜者]
    C -->|小组赛| D2{比分大小判定}
    D2 -->|选手1分高| D3[结果=选手1胜]
    D2 -->|选手2分高| D4[结果=选手2胜]
    D2 -->|比分相同| D5[结果=平局]
    D --> E[写入比分+winner+状态=已结束]
    D3 --> E
    D4 --> E
    D5 --> E
    E --> F[调用算分函数 calcMatchPoints]
    F --> G{结果?}
    G -->|胜| G1[胜者+3 胜场+1]
    G -->|平| G2[双方各+1 平局+1]
    G -->|负| G3[负者+0 负场+1]
    G1 --> H[更新净胜分]
    G2 --> H
    G3 --> H
    H --> I[刷新小组实时排名]
    I --> J{该小组全部比赛结束?}
    J -->|否| K[结束 等待下一场]
    J -->|是| L[触发晋级判定流程]
```

---

## 6. 小组赛晋级判定（含同分排序）

```mermaid
flowchart TD
    A[小组全部比赛结束] --> B[按多级规则排序]
    B --> C[1.比赛积分降序]
    C --> D[2.比赛积分相同→比胜场]
    D --> E[3.仍相同→比净胜分]
    E --> F[4.仍相同→比相互对战胜负]
    F --> G{仍然完全相同?}
    G -->|是| G1[标记同分 提示人工裁定]
    G -->|否| H[确定组内最终名次]
    G1 --> H
    H --> I[读取出线名额 N]
    I --> J[前N名标记: 晋级]
    J --> K[其余标记: 淘汰]
    K --> L[晋级选手进入下一轮赛事池]
```

---

## 7. 淘汰赛逐轮推进（含复活）

```mermaid
flowchart TD
    A[本轮全部对战结束] --> B[收集本轮所有胜者]
    B --> C{是否启用复活?}
    C -->|是| C1[按败者比赛积分降序取前K名复活]
    C -->|否| D[仅胜者进入下一轮]
    C1 --> D
    D --> E{剩余人数 == 1?}
    E -->|是| F[产生冠军 赛事结束]
    E -->|否| G[按签位生成下一轮对阵]
    G --> H{有轮空?}
    H -->|是| H1[轮空选手直接晋级]
    H -->|否| H2[生成下一轮正常对战]
    H1 --> I[下一轮赛程生成完成]
    H2 --> I
    I --> J[继续录入比分]
```

---

## 8. 赛事积分结算（运营积分，独立于晋级）

```mermaid
flowchart TD
    A[点击赛事积分结算] --> B[遍历每位参赛选手]
    B --> C{是否弃赛/违规?}
    C -->|是| C1[不发积分 记录流水=0]
    C -->|否| D[发放到场完赛分]
    D --> E{赛事类型?}
    E -->|周赛| E1[+10]
    E -->|月赛| E2[+30]
    E -->|年终赛| E3[+80]
    E1 --> F[判断最终名次]
    E2 --> F
    E3 --> F
    F --> G{获得名次?}
    G -->|冠/亚/季| G1[叠加对应名次奖励分]
    G -->|无名次| G2[不加名次分]
    G1 --> H[判断额外加分项]
    G2 --> H
    H --> H1{兼报2组别且全完赛?}
    H1 -->|是| H2[每场+5]
    H --> H3{连续参加2期及以上?}
    H3 -->|是| H4[每期+3]
    H2 --> I[汇总写入积分流水]
    H4 --> I
    C1 --> J[累加更新全年总积分]
    I --> J
    J --> K{还有下一位选手?}
    K -->|是| B
    K -->|否| L[结算完成 刷新积分总榜]
```
