# 极简登录功能增删改查 PRD

## 一、文档说明

核心目标：实现最基础的账号登录、账号管理增删改查功能，无多余拓展能力，满足基础后台权限登录使用。

适用端：用户端（前台登录）、管理端（账号管理）、服务端（数据逻辑处理）

功能范围：仅包含账号登录、账号新增、账号查询、账号编辑、账号删除五大核心能力

## 二、整体角色定义

1. 普通用户：仅拥有账号登录权限
2. 管理员：拥有账号增删改查 + 登录权限

## 三、用户端功能（仅登录）

1. 核心功能：账号登录
2. 输入项：账号、密码
3. 交互逻辑：
   - 输入正确账号密码：校验通过，跳转系统首页
   - 输入错误：提示「账号或密码错误」
   - 空输入：提示「请输入账号/密码」
4. 附加规则：登录成功生成会话 Token，有效期默认 2 小时，过期需重新登录

## 四、管理端功能（账号增删改查）

1. 查询：展示所有系统账号列表（账号、创建时间、账号状态），支持按账号关键词模糊查询
2. 新增：账号唯一不可重复，默认状态为正常
3. 编辑：可重置密码、修改账号状态，不可修改账号名称
4. 删除：二次确认后永久删除，不可删除当前登录的管理员账号

## 五、服务端功能

1. 登录：校验账号存在、状态正常、密码匹配，成功生成 Token
2. 增删改查：密码 MD5 加密存储，管理端接口需管理员权限
3. Token 过期自动失效

## 六、异常规则

1. 账号禁用：无法登录，提示「账号已被禁用」
2. 账号重复：新增时提示「账号已存在」
3. 权限不足：普通用户无法访问管理端账号管理
