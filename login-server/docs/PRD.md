# 极简登录功能增删改查 PRD

## 一、文档说明

**核心目标**：实现最基础的账号登录、账号管理增删改查功能，无多余拓展能力，满足基础后台权限登录使用。

**适用端**：
- 用户端（前台登录）
- 管理端（账号管理）
- 服务端（数据逻辑处理）

**功能范围**：仅包含账号登录、账号新增、账号查询、账号编辑、账号删除五大核心能力。

## 二、整体角色定义

1. **普通用户**：仅拥有账号登录权限
2. **管理员**：拥有账号增删改查 + 登录权限

## 三、用户端功能（仅登录）

1. **核心功能**：账号登录
2. **页面入口**：系统默认登录页
3. **输入项**：账号、密码
4. **交互逻辑**：
   - 输入正确账号密码：校验通过，跳转系统首页
   - 输入错误：提示「账号或密码错误」
   - 空输入：提示「请输入账号/密码」
5. **附加规则**：登录成功生成会话 Token，有效期默认 2 小时，过期需重新登录

## 四、管理端功能（账号增删改查）

管理员登录后，可进入【账号管理】页面，对所有登录账号进行管理。

### 1. 查询（查）

- 展示所有系统账号列表
- 列表字段：账号、创建时间、账号状态（正常/禁用）
- 简易搜索：支持按账号关键词模糊查询

### 2. 新增（增）

- 入口：账号列表【新增账号】按钮
- 必填输入项：账号、初始密码
- 规则：账号唯一、不可重复；新增后账号默认状态为正常

### 3. 编辑（改）

- 入口：账号列表对应数据【编辑】按钮
- 可修改内容：重置密码、修改账号状态（正常/禁用）
- 限制：不可修改账号名称

### 4. 删除（删）

- 入口：账号列表对应数据【删除】按钮
- 交互：点击弹出二次确认弹窗，确认后永久删除账号
- 限制：不可删除当前登录的管理员账号

## 五、服务端功能（逻辑 + 数据处理）

1. **登录接口逻辑**
   - 接收用户端账号、密码参数
   - 校验账号是否存在、状态是否正常、密码是否匹配
   - 校验成功生成 Token 返回前端，失败返回对应错误提示

2. **增删改查接口逻辑**
   - 新增：校验账号唯一性，加密存储密码，写入账号数据
   - 查询：接收搜索参数，筛选并返回账号列表数据
   - 编辑：更新账号密码（加密）、账号状态信息
   - 删除：校验非当前登录账号，删除对应数据

3. **基础数据规则**
   - 密码全程 MD5 加密存储，明文不入库
   - 所有接口需校验管理员权限（除用户登录、管理员登录接口）
   - 会话 Token 过期自动失效，需重新登录授权

## 六、简单异常规则

1. 账号禁用：无法登录，提示「账号已被禁用」
2. 账号重复：新增账号时提示「账号已存在」
3. 权限不足：普通用户无法访问管理端账号管理页面
