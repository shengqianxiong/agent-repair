# aiProduct5 豆评助手用户端 PRD

## 1. 产品定位

豆评助手面向消费者完成“扫码领取评价任务 -> 复制 AI 文案 -> 跳转抖音评价 -> 上传截图 -> 商家审核返利”的闭环流程。用户端仅承载 C 端任务执行、记录查询和返利状态查看。

## 2. 页面与路由

| 页面 | 路由 | 说明 |
|---|---|---|
| 扫码任务页 | `/pages/task/index?code=xxx` | 根据二维码 code 获取活动，展示商品、AI 文案、推荐图片和任务步骤 |
| 评价提交页 | `/pages/task/submit?id=xxx` | 上传评价截图，填写备注与联系方式，确认提交返利审核 |
| 提交结果页 | `/pages/task/result?auditId=xxx` | 展示提交成功、审核进度与后续入口 |
| 个人中心 | `/pages/user/center` | 展示累计返利、待审核、已到账与历史入口 |
| 评价记录页 | `/pages/user/records` | 按状态筛选评价任务，展示返利金额、拒绝原因与详情入口 |
| 返利详情页 | `/pages/rebate/detail?id=xxx` | 展示单笔返利状态、关联活动、截图和审核结果 |

## 3. 核心流程

1. 用户扫码进入 `/pages/task/index?code=xxx`。
2. 页面调用 `/app/activity/by-code` 获取活动信息，并调用 `/app/task/start` 记录扫码开始任务。
3. 用户选择 AI 文案并复制，页面调用 `/app/task/copy-report` 上报行为。
4. 用户保存推荐图片或打开抖音发布评价。
5. 用户点击“我已评价”进入提交页，上传评价截图并提交 `/app/task/submit`。
6. 提交成功进入结果页；后续可在记录页和返利详情页查看审核与到账状态。

## 4. 视觉规范

- 主色：`#1463ff`，用于导航高亮、主按钮和关键状态。
- 辅助色：成功 `#25c06d`、警告 `#ff9f18`、错误 `#ff5a5f`。
- 背景：页面浅灰 `#f6f8fc`，内容卡片白色。
- 卡片圆角：28rpx-32rpx；按钮圆角使用胶囊形态。
- 字级：标题 32rpx-38rpx，正文 26rpx-28rpx，辅助说明 23rpx-24rpx。

## 5. 验收标准

- 所有页面已在 `pages.json` 注册，可通过 TabBar 或按钮闭环导航。
- 所有接口调用统一经过 `src/common/httpRequest.js`，请求携带 header `token`。
- 后端不可用时，页面可用同结构演示数据完成 H5 交付验收。
- H5 运行端口固定为 8080。
